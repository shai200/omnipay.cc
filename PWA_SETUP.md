If you're using VS Code, install the PWA extension:
1. Search "PWA" in Extensions
2. Install "PWA" by Microsoft

For testing locally:
1. Build: npm run build
2. Start: npm start
3. Open https://localhost:3000 (you may need to bypass cert warnings)
4. Check Lighthouse audit (DevTools > Lighthouse)

For Play Store checklist:
✓ Manifest.json (created)
✓ Service Worker (auto-generated by next-pwa)
✓ HTTPS (required for production)
✓ Icons (192x192, 512x512, maskable variants)
✓ Responsive design
✓ Offline support (runtime caching configured)
✓ Display: standalone
